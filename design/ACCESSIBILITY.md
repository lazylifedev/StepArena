# Accessibility

- Material コンポーネントの 48 dp 以上のタップ領域を維持する。
- カスタム進捗リングには値域と読み上げ文を設定する。
- 計測状態は色、点、文言を併用する。
- 数字と単位を同じ意味単位として読み上げる。
- 見出し semantics で情報階層を伝える。
- 大きなフォントでは固定高カードを避け、縦スクロールで全操作へ到達可能にする。
- Reduced / Off モーションを提供する。
- 装飾要素は読み上げ順を乱さず、下部ナビゲーションはラベルで目的を伝える。

TalkBack、フォント 1.6 倍、小型画面、コントラスト、スイッチアクセスを実機リリースゲートに含める。
