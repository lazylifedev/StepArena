# Design Concept: Pulse Arena

歩数がエネルギーとして流れ、毎日の歩行が試合になる未来的なスポーツ UI。健康管理の信頼性と対戦ゲームの高揚感の中間を狙う。

キーワードは Future Motion、浮遊感、深度、流動、脈動、精密、高級感、競技性、軽快さ、直感性。視線は「計測状態 → ランク → 今日の歩数 → 目標 → 活動指標 → マッチ → 開始 → リーグ」の順に誘導する。

過剰なネオン、低コントラストの透明カード、常時動く背景、全面ブラー、色だけの状態、過密なゲーム UI は避ける。Material 3 のアクセシビリティ基盤を利用しながら、色・形・余白・階層で独自性を作る。
