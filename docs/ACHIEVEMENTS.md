# 実績

実績は定義と評価処理をゲームRepository境界に置き、主キーとINSERT IGNOREで重複解除を防ぐ。条件は画面に開示する。歩数、継続、対戦、ランク、信頼性、セッションを対象とし、ログインだけを求める報酬や過剰歩行を促す条件は設けない。
# Phase 5.1 初期実績

初回1,000歩、3/7日連続計測、初勝利、3/5連勝、1日10,000/20,000歩、
Silver昇格、1シーズン10試合、補完なし7日連続、欠測補完成功を対象とする。
主キーで重複解除を防ぎ、`progressValue` を保存する。UNKNOWNのみの日や
NO_CONTESTは歩数・勝利実績へ算入しない。
