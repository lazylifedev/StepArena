# ユーザー向け用語

StepArena はゲーム性を持つ歩数計アプリです。内部モデル、DB、enum の名前は互換性のため維持し、公開 UI では次の表現を使います。

| 内部・旧表現 | 公開 UI |
| --- | --- |
| 対戦 / マッチ | チャレンジ |
| デイリー対戦 | 今日のチャレンジ |
| 対戦相手 / NPC | チャレンジパートナー / パートナー |
| 勝利 / 敗北 / 引き分け | 目標達成 / あと一歩 / 同じ歩数 |
| rating / RP | 歩行レート |
| ランク / 昇格 | 歩行ランク / 歩行ランク更新 |
| リーグ | 週間グループ |
| シーズン | 月間記録 |
| 実績 | 達成記録 |
| 連勝 | 連続達成 |
| You | あなた |

`WIN`、`ACTIVE`、`MEASURED` などの enum 値、内部 ID、`participantJson` は公開 UI に直接表示しません。日付は `yyyy年M月d日`、月は `yyyy年M月`、数値はロケールに応じた桁区切りと単位を付けます。

チャレンジパートナーと週間グループの参加者は端末内で自動生成され、実在ユーザーとのオンライン対戦ではないことを説明します。
