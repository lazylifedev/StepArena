# Ranking Rules

## 仮ルール

ランクは Bronze、Silver、Gold、Platinum、Diamond とし、各ランクに Division を持つ。ランクポイント（RP）と次ランクまでの RP を分離して表示する。

日次マッチは双方の歩数そのものではなく、個別目標に対する達成率を基本比較値とする。これにより体格や生活条件が異なる参加者間の公平性を高める。週間リーグは指定期間に得たリーグポイントで順位を決め、昇格圏との差を表示する。

## 未確定事項

- 目標値の決定方法と最低・最大値
- 同率、欠測、タイムゾーンをまたぐ対戦の扱い
- 不正検知、補完データ、Health Connect データの得点可否
- 月間シーズン終了時の降格・報酬

Phase 0・1 の数値はデザイン評価用で、実ランキング結果ではない。
