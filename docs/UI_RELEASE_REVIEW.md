# Phase 6.3 公開 UI レビュー

## 実装済み

- 下部ナビゲーションを Material アイコンと「ホーム / チャレンジ / 記録 / 達成 / 設定」に統一
- Home のチャレンジ、パートナー、週間グループ、歩行レート表現を統一
- チャレンジ、歩行ランク、週間グループ、月間記録、達成記録で内部 enum と技術名を非表示化
- Records の未実装期間 Chip を非表示化し、Chip を横スクロール対応
- 時間別グラフの固定空白ラベルを廃止し、0時・12時・23時をレイアウト配置
- グラフ全体の TalkBack 要約を追加
- オンボーディングを縦スクロール、見出し semantics、全幅操作ボタンに対応
- 設定行にアイコン、補足説明、状態、Chevron、48dp 以上の操作領域を追加
- Home から MotionPreview を撤去し、設定側に「画面の動き」を配置

## 手動確認項目

- 320dp 幅、200% フォント、Landscape で全画面のスクロールとボタン到達性
- TalkBack で下部ナビ、グラフ、設定行、チャレンジ結果の読み上げ
- Light / Dark でカード、背景、進捗表示のコントラスト
- Release ビルドで Debug 専用画面・識別子・内部 enum が露出しないこと

週別・月別 Records は集計データと画面設計を同時に導入する将来範囲とし、未完成 Chip は Release UI に表示しません。
