# Localization Policy

表示文言、状態名、ランク名、称号名、通知、エラー、アクセシビリティ文言は Android リソースに置く。文章を文字列連結で組み立てず、書式引数と将来の `plurals` を使う。ダミーのユーザーデータは UI 固定文言と分離する。

単位変換と書式化は `core/units` に集約し、画面で換算しない。距離、速度、体重、身長、時刻形式、週開始曜日を将来のロケール・ユーザー設定から選べるようにする。数値は `Locale` に従う。

時刻は保存・通信に `Instant`、日次集計に `LocalDate` と集計時の `ZoneId`、表示に端末またはユーザー設定の `ZoneId` を使う。日本時間へ固定しない。

初回公開は日本語のみだが、英語の長い文言、複数形、RTL、文字拡大でレイアウトが破綻しないことを後続の翻訳導入前にも確認する。
