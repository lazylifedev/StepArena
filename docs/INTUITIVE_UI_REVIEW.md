## Phase 7.2.1 目標歩数の正本

`DailyStepGoalRepository` をユーザーの1日目標の唯一の正本とする。既定値は
10,000歩であり、Homeのリング、Recordsの日別歩数、常駐通知、達成判定、
エクスポートが同じ値を読む。チャレンジの5,483歩は自動生成パートナーの目標で、
ユーザーの1日目標とは別の値である。

| 表示・処理 | Phase 7.2.1 |
|---|---|
| Home | 合計歩数と `DailyStepGoalRepository` の目標でリングを計算 |
| Records | 日別歩数で同じ目標を表示 |
| 常駐通知 | 端末実測歩数 / 同じ目標を表示 |
| 達成判定 | 1日目標の閾値を同じ正本から取得 |
| エクスポート | `settings.json` に `dailyStepGoal` を記録 |

## Phase 7.2.1 チャレンジ文字監査

| 変更前の通常表示 | 分類 | Phase 7.2.1 |
|---|---|---|
| 毎日の歩数をパートナーと比べる2文 | 情報Sheetへ移動 | 右上の情報アイコンから表示 |
| 今日の進捗 | 重複 | 削除 |
| パートナー目標 n歩 | 主情報 | 紫の人物・数値・バーへ置換 |
| チャレンジ対象歩数 n歩 | 主情報 | シアンの人物・数値・バーへ置換 |
| 目標を達成しました | 状態 | チェック、Emerald、短い「達成」へ置換 |
| あと n歩 | 状態 | 旗アイコンとともに維持 |
| Health Connectから追加されたn歩は対象外 | 情報Sheetへ移動 | 追加がある時だけ `合計 n　対象 n　ⓘ` を通常表示 |
| 端末で直接計測した歩数だけを使用 | 情報Sheetへ移動 | 通常表示から削除 |
| 30,000歩上限の長文 | 情報Sheetへ移動 | 上限適用時だけAmberの短い状態を表示 |

比較カードは、ユーザーをCyan、パートナーをViolet、ゴールを旗で表す。双方の
アイコン、数値、横バーを一つのまとまりにし、TalkBackでは
「あなたn歩、パートナーn歩、あとn歩」または「達成」を一度で読む。

## Phase 7.2.1 モーション

- 歩数増加: FULL 520ms、REDUCED 140ms、OFF 即時でユーザーバーを更新する。
- パートナー超過・ゴール到達: FULLは短いEmerald光と旗のscale、REDUCEDは短い色変化、
  OFFは静的な達成状態だけを表示する。
- 再生済み日次チャレンジIDを永続化し、再表示や再構成で演出を繰り返さない。
- 未達時の敗北演出、点滅、無限ループは使用しない。

## 全公開画面の文字分類と段階境界

| 画面 | 主情報・操作・状態 | 移動／削除候補 | 実装Phase |
|---|---|---|---|
| Home | 合計歩数、目標、計測、ウォーキング、活動3指標 | 重複見出し、速度、推定説明 | 目標のみ7.2.1、整理は7.2.4 |
| チャレンジ | 双方の歩数、バー、旗、達成／残り | 方式、Health Connect、上限説明をSheetへ | 7.2.1実装 |
| 歩行ランク | 徽章、ランク、進捗、残り | 現在／次／ポイントの重複語 | 7.2.4設計 |
| 週間グループ | 順位、人数、昇格線、バー | 自動生成説明、重複ラベル | 7.2.4設計 |
| 月間記録 | 月歩数、平均、最高日、日別グラフ | 長い集計説明 | 7.2.4設計 |
| Records | 期間、指標、グラフ、選択時間帯 | UTC、品質、全指標列を詳細／診断へ | 目標のみ7.2.1、再設計は7.2.3 |
| 達成記録 | バッジ、短い名前、進捗、達成日 | 条件説明をSheetへ | 7.2.2設計 |
| 設定 | アイコン、項目名、現在値、Chevron | 補足を詳細／Sheetへ | 7.2.4設計 |

通常表示の本文は原則1行以内とし、主情報、操作、状態に必要な文字は残す。
単に削除せず、数字、アイコン、色、形、進捗、情報Sheetへ役割を移す。

## Phase 7.2.2 達成記録の設計

- 2列Gridを基本とし、200%文字と320dp幅では1列へ縮退できる構造にする。
- 達成済みは色付きバッジ、チェック、Cyan/Violet輪郭、新規ドット、必要時だけ達成日。
- 未達成は低彩度、暗い輪郭、鍵または未完成リング、`0/3`など短い進捗。
- 通常一覧から条件文を除き、タップ可能なバッジだけscale 0.98とButton roleを付ける。
- BottomSheetに名称、条件、現在進捗、達成日を置き、色だけに依存しないsemanticsを付ける。
- 既存の達成判定、通知、公開IDフォールバックは変更せず、表示層だけを置換する。
