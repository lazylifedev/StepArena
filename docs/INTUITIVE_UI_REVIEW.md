# Intuitive UI Review

## Phase 7.1 Home

| 変更前の通常表示 | 分類 | Phase 7.1 |
|---|---|---|
| `TODAY'S STEPS` | 重複 | 削除 |
| 今日の一歩を、楽しい習慣へ。 | 削除可能 | 削除 |
| 今日の歩数 | 必須ラベル | リング上部に維持 |
| 正常に計測中 | 状態 | `計測中`相当の小型チップに短縮 |
| 最終正常確認時刻 | 詳細へ移動可能 | 通常Homeから削除。計測診断で確認 |
| 推定・復旧・オフライン補足 | 詳細へ移動可能 | 通常Homeから削除。診断情報として扱う |
| 端末で計測 n歩 | 状態 | 端末アイコン + 数値へ置換 |
| Health Connectから追加 n歩 | 状態 | 追加がある時だけアイコン + `+n`。タップで内訳 |
| 目標 n歩 / n% | 必須ラベル | リング内の短い1行を維持 |
| ウォーキング記録 | 必須ラベル | クイックアクションに維持 |
| ウォーキングの2文説明 | 初回のみ必要 | 情報BottomSheetへ移動 |
| ウォーキング記録中 | 状態 | 時間・歩数・停止アイコンへ置換 |
| 歩数計測を停止 | 必須操作 | 安全操作として維持 |
| 距離・時間・カロリー・速度 | 必須指標 | Home下部に維持 |

## 情報階層

1. 日付
2. 今日の合計歩数と目標リング
3. 端末実測と、存在する場合だけHealth Connect追加
4. 小型の計測状態
5. ウォーキングクイックアクション
6. 距離・時間・カロリー・速度
7. Phase 7.2以降で扱うランク・チャレンジ・リーグ

## 他画面のPhase境界

- GameScreen: Phase 7.2で通常表示の長文と視覚比較を監査する。
- RecordsScreen: Phase 7.3で指標・期間ラベルとアイコンを監査する。
- Achievements: Phase 7.3で条件説明を詳細Sheetへ移しGrid化する。
- Settings: 設定名は選択のための必須ラベルとして維持し、最終監査はPhase 7.4で行う。

## 画像アセット

Phase 7.1ではMaterial IconsとCompose描画だけを使用する。外部PNG、生成画像、新規画像仕様は不要。
