# Foreground Service 申告草案

- type: `health`
- 用途: ユーザーが開始した歩数計測を、画面を閉じた後も継続する。
- 開始: オンボーディング完了画面またはHomeの「計測開始」。
- 認識可能性: 計測中は永続通知を表示。アプリまたは通知から停止できる。
- WorkManagerで代替できない理由: センサーイベントの継続受信は遅延可能な単発処理ではない。
- 権限: 身体活動の説明後にACTIVITY_RECOGNITION、Android 13+は通知用途の説明後にPOST_NOTIFICATIONS。
- 審査動画: 初回説明 → 権限 → 計測開始 → 永続通知 → 停止の順に撮影する。

Play Consoleで申告が要求される場合、最新フォームと動画要件を確認する。
