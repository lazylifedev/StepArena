# 対戦有効歩数

実測は100%、復旧歩数は80%、Health Connect等の外部補完は70%、推定は50%、UNKNOWNは0%を初期値とする。外部補完の計算対象は1日10,000歩、全体の対戦有効歩数は30,000歩が上限である。

負数、オーバーフロー、1日100,000歩超、Debugデータなどの異常は元記録を消さず対戦利用のみ除外し、理由をマッチへ保存する。UIでは「公平性のため制限」と中立的に説明する。
